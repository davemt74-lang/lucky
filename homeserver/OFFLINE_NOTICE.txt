LUCKY GAME HUB HOMESERVER — WINDOWS OFFLINE PREVIEW

The installed application footer and app/release.json identify the release.
app/build-info.json records its exact Git commit and source tree.

This installer contains the complete application and locally executed components:
PHP, MariaDB, Caddy and FFmpeg. After installation, the product requires
NO CLOUD ACCOUNT, CLOUD DATABASE or DOWNLOADS for basic game functions.

ALL DATABASES, MEDIA, SESSIONS AND PROOF RECORDINGS REMAIN ON THIS COMPUTER.
Data location: %LOCALAPPDATA%\LuckyGameHub
First-admin setup: http://127.0.0.1:8833/first-admin.php
Home PC console: http://127.0.0.1:8833
LAN controller (when available): https://YOUR-LAN-IP:8843

IMPORTANT:
1. On another phone or computer, the Caddy HTTPS certificate is generated by
   the HomeServer's own CA; mobile devices will not trust it automatically.
   Certificate trust and real mobile camera access are NOT YET CERTIFIED.
2. An incoming Windows Firewall permission may be required for port 8843.
   Do not forward this port on your router or expose it to the internet.
3. Online video URLs such as YouTube are not available offline; local media
   is available. No telemetry or remote license check is required.
4. The application may be stopped by closing the HomeServer process.
   The optional startup shortcut can launch it at Windows sign-in.
   The launcher can replace an exited PHP worker without restarting the local
   database. Interrupted requests are not automatically replayed: check the
   saved result before retrying. Repeated worker failures stop the stack and
   record a diagnostic in the local logs.
5. Uninstall removes the program, but user data remains in
   %LOCALAPPDATA%\LuckyGameHub until you deliberately erase it after backup.
6. Unsigned pre-release Windows installers may display SmartScreen warnings.
   Check the checksum and installer source before running.
7. Automated Windows install/restart/runtime checks are release gates.
   Physical-device, WAN-disconnected, mobile camera and backup/restore
   certification is ongoing. Do not treat this preview as a certified consumer
   release.
